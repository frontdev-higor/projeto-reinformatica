# 🖥️ RE Informática e Suprimentos

Site institucional e catálogo de produtos da **RE Informática e Suprimentos**, loja de venda e manutenção de computadores localizada em Goiânia-GO.

🔗 **Site:** [reinformaticaesuprimentos.com.br](https://reinformaticaesuprimentos.com.br)

## O que tem no site?

- **Página inicial** — Apresentação da loja com destaques e navegação principal
- **Catálogo de produtos** — Computadores, monitores, componentes e equipamentos organizados por categoria, com imagens e especificações
- **Serviços** — Manutenção, formatação e outros serviços oferecidos pela loja
- **Sobre** — Informações sobre a empresa
- **Contato** — Formulário e dados para contato

## Tecnologias

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Font Awesome (ícones)

## Estrutura do projeto

```
├── index.html              → Página inicial
├── servico.html            → Página de serviços
├── sobre.html              → Sobre a empresa
├── contato.html            → Página de contato
├── itens.html              → Detalhes de itens
├── tipo-computador.html    → Catálogo de computadores
├── tipo-monitor.html       → Catálogo de monitores
├── tipo-componente.html    → Catálogo de componentes
├── tipo-equipamento.html   → Catálogo de equipamentos
├── css/                    → Estilos do site
├── js/                     → Scripts (navegação, filtros, dados dos itens)
└── imagens/                → Fotos dos produtos por categoria
```

## Responsividade

O site é responsivo e se adapta a dispositivos móveis, tablets e desktops utilizando o grid system do Bootstrap.
